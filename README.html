Как пользоваться тренажёром

1. Распакуйте весь ZIP-архив и откройте файл index.html в браузере.

2. На главной странице выберите один из 25 билетов. Для каждого билета создан отдельный HTML-файл bilet-01.html — bilet-25.html.

3. Прочитайте оригинальное письменное задание из PDF и отметьте варианты в тесте (A/B/C/D — там, где они есть).

4. Напишите свой вариант исправленного текста в поле ответа. Нажмите «Проверить ответы» — откроются правильные варианты и пояснения на русском языке.

5. Сравните свой ответ с образцом и выберите «Пройдено» или «Нужно повторить».

6. Прогресс и черновики хранятся в локальном хранилище этого браузера на этом устройстве. Они не синхронизируются между iPhone и ноутбуком; в режиме приватного просмотра могут не сохраняться.

Для публикации в GitHub Pages загрузите все файлы из архива в корень репозитория и включите Pages: Branch → main → /(root). После этого сайт будет доступен по ссылке.

Важно об источнике

Составлено на основе «Билеты по русскому языку.pdf» (9 страниц, 25 билетов). В источнике билет №5 начинается не полностью, у №8 размыто начало инструкции, у №17 отсутствует фотография заголовка. Эти ограничения отмечены внутри тренажёра. Орфография примеров и отдельные особенности исходных формулировок сохранены, а правильные решения и пояснения составлены отдельно как учебные образцы.

Тренажёр автоматически проверяет только ответы с выбором вариантов. Свободная редакция может иметь несколько правильных формулировок и оценивается вами по образцу. Ответы не являются официальным ключом экзамена.
