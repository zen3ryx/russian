ИНТЕРАКТИВНЫЕ БИЛЕТЫ ПО РУССКОМУ ЯЗЫКУ

1. Распакуйте архив полностью.
2. Откройте index.html в браузере.
3. Выберите один из 25 билетов.
4. Ответьте на тестовые вопросы и напишите собственную редакцию.
5. Нажмите «Проверить ответы», сравните текст с образцом.
6. Отметьте билет как пройденный или отправьте на повторение.

Работает полностью офлайн. Сохраняет ответы локально в браузере, не синхронизирует их между устройствами.
Для GitHub Pages загрузите все файлы в один репозиторий.

Источник: «Билеты по русскому языку.pdf», 25 билетов на 9 страницах.
Ответы составлены для тренировки, это не официальный экзаменационный ключ.
